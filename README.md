Guild Quests Board
Guild Quests Board is an addon for World of Warcraft Classic Anniversary that transforms scattered guild chat messages into a structured guild quest and task management system.

Create guild quests, assign rewards, schedule events, gather groups, and track progress from a single shared board.

Instead of repeatedly posting messages like "Need a tank for Stratholme", "Can anyone help with this quest?" or "Paying 50 gold for crafting", simply create a quest that every guild member using the addon can see.

Features
📋 Create guild quests and tasks
💰 Gold rewards
👥 Multiple participants
📅 Scheduled events and deadlines
🔔 New quest notifications
📖 Complete activity history
🔍 Search and filtering
🌍 English and Russian localization
🔄 Fully decentralized peer-to-peer synchronization
No External Server Required
Guild Board does not require any external server or database.

All data is synchronized directly between players using the World of Warcraft addon messaging system. Every user stores a local copy of the guild database, making the addon completely self-contained and serverless.



Guild Quests Board
Guild Quests  Board — это аддон для World of Warcraft Classic Anniversary, который превращает хаотичные сообщения в гильдейском чате в удобную систему заданий.

Создавайте задания для членов гильдии, назначайте награды, указывайте дедлайны или время проведения события, собирайте группы и отслеживайте прогресс выполнения в одном месте.

Вместо постоянных сообщений вроде «Нужен танк в Стратхольм», «Кто может помочь с квестом?» или «Заплачу 50 золота за крафт» вы можете создать полноценное задание, которое увидят все игроки с установленным аддоном.

Без сервера
Guild Board не использует внешний сервер или базу данных.

Вся информация синхронизируется напрямую между игроками через систему сообщений аддонов World of Warcraft. Каждый участник хранит локальную копию базы данных, что делает аддон полностью автономным.
